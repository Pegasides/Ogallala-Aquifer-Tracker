## Purpose

Version 3.1 needed a browser smoke workflow that tests the branch itself without changing `main`, the live GitHub Pages deployment, `version-2.0-sacred`, or `version-3.0-sacred`.

The existing workflow `.github/workflows/v3-smoke-test.yml` remains unchanged and still targets `main` / the deployed GitHub Pages site.

A separate Version 3.1 QA path was added:

- `.github/workflows/v3-1-smoke-test.yml`
- `scripts/v3-1-smoke.mjs`

The Version 3.1 workflow triggers on pushes to `version-3.1-working` for relevant V3.1 files. It checks out the branch commit, starts a local Python static server at `http://127.0.0.1:8000/`, and runs Playwright Chromium against those local branch files.

This means the QA result reflects Version 3.1 itself, not whatever happens to be deployed from `main`.
