# Version 3.1 — Sources That Inform Our Story audit

Date: 2026-08-12
Branch: `version-3.1-working`

## Purpose

Version 3.1 treats source transparency as part of the product, not as decorative credits. The public-facing `sources.html` page is a live, accessible source directory with current primary-source links and explicit integrity rules separating measurement, Tracker interpretation, context, and scenarios.

The preserved **Sources That Inform Our Story** poster remains the visual design reference. It is **not published unchanged as the current source directory** because several details on the raster graphic require correction before it can be represented as current.

## Integrity rules published in Version 3.1

1. **Tracker index ≠ percentage of aquifer water remaining.**
2. **Regional context ≠ a measurement at a specific city, home, or well.**
3. **Infrastructure context ≠ causation or attribution.**
4. **2050 scenario ≠ measured future condition or guaranteed forecast.**
5. **Company statements ≠ independent hydrologic findings unless separately supported.**
6. **Groundwater Window illustration ≠ surveyed engineering profile or verified monitoring-well record.**

## Poster handling

The preserved raster poster should be retained as a design/reference asset. Before a corrected raster version is published in either the Tracker or the Substack/publication context, its agency names, URLs, dates, source wording, and logos should be rechecked against the live source directory.

The live HTML source directory is the controlling Version 3.1 public reference because its text and links can be corrected without regenerating an image.
